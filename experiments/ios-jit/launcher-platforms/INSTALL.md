# Install build35

The unsigned IPA is a private owner test build. Preserve app data when updating.

- **LiveContainer:** Cabrillo in slot1; choose StikDebug in slot2 or standalone StikDebug in Settings. Keep JIT off and saved script blank in LiveContainer. Use Cabrillo’s fresh request.
- **Standalone + StikDebug:** iOS17.4 or later, with `get-task-allow` on the signed app. Select Standalone StikDebug. Return to the same process after activation.
- **iOS15 / TrollStore:** install using TrollStore. Choose its JIT route (URL scheme enabled) or Open with JIT, then Check JIT. A jailbreak may already grant the permission. No StikDebug installation is needed on iOS15.

Read README-FIRST.txt for device-specific and Motion Smoothing checks. Export diagnostics remains available independently of USB collection.
