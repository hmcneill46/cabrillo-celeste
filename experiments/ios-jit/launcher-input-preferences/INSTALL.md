# Installing build57 for testing

Use the unsigned IPA in the private test kit. In LiveContainer replace Cabrillo
and retain its data container. Keep the existing shortcut49. Obtain fresh JIT
for the new process. Verified original game files may rebuild their prepared
cache once; no new game ZIP should be needed.

Settings → Controls → Customize touch controls opens the editor. During play,
use Pause → Touch controls… → Details → Behavior. Save applies changes live.
See PHONE_README.txt for the focused device checks. Quit Celeste normally and
export diagnostics into this build's Results folder.
