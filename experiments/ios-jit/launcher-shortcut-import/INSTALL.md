# Build49 installation

Replace the existing Cabrillo guest in LiveContainer, keeping its data container.
Let an active game finish with normal Quit first. Leave LC JIT off, its saved
script blank and Fix File Picker on. In Cabrillo Settings → Home Screen shortcut,
use Add Home Screen shortcut, copy/save the file and paste the launch link into
Apple's blank text field. Keep exactly one shortcut named Cabrillo.

For the immediate48 import repair, the standalone Cabrillo.shortcut in the49 kit
is the LiveContainer template and works with installed app48. Copy your launch
link in Cabrillo first, cancel the old setup screen and import the supplied49 file.
Do not use app48's old exported file. App49 includes the repair for future exports.
See README-FIRST.txt in the kit and docs/HOME_SCREEN_SHORTCUT.md.
