# Cabrillo 0.23.1 — shortcut import repair (build49)

Build48's LiveContainer import question binds directly to Apple's URL-list editor.
On iOS26.5 that editor restores the old value while the owner types. This lane asks
for plain text instead. It starts blank, preserves edits, and converts the result
through an explicitly connected URL action. An empty answer opens Cabrillo's setup
help. JIT handoff links retain their separate typed URL connection.

The49 shortcut works with app48 or later. App49 bundles the corrected files for
future in-app exports. All199 managed assemblies,16 archives, SwiftUI sources and
the47 launch reducer remain exact48. Only the template revision check/export event
and build metadata change in the native launcher.

See the [49 report](../../../docs/ios-jit/SHORTCUT_IMPORT_BUILD_49.md),
[setup guide](../../../docs/HOME_SCREEN_SHORTCUT.md) and
[build instructions](../../../docs/BUILDING.md). Simulator import/routing evidence
is separate from physical JIT/gameplay acceptance. Public IPA distribution remains
gated on FMOD permission; no new publication is authorized.
