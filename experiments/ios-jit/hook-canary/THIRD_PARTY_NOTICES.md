# Hook canary provenance

The custom Mono runtime is built from dotnet/runtime **v8.0.28**, commit
`46295af5828b062bbbf93a9cef50fd8cb9fbcb09`. The .NET Foundation and its
contributors license this code under MIT; individual files retain their
copyright notices. The bounded alias modifications are recorded in
`runtime-alias.patch`, generated by `patch-runtime.py` against that revision.

The framework IL and `libSystem.Native.a` come from the matching official
`Microsoft.NETCore.App.Runtime.Mono.ios-arm64` **8.0.28** package. The package's
`LICENSE.TXT` and `THIRD-PARTY-NOTICES.TXT` are included in the app. The stock
Mono AOT archive in that package is not linked. The custom runtime and its
marshal IL generator/stub components are built together from the pinned source.

The fixture is compiled with the official .NET SDK **8.0.422**. Its SHA-512 and
the runtime package digests are pinned in `runtime-pin.json`. The SDK is a build
dependency and is not shipped in the app.

The native launcher, VM-range walker and M1 debugger script extend this
repository's earlier native probe. The script is an independent implementation
of the documented StikJIT/Apple debugserver protocol. No StikDebug or
LiveContainer library is embedded. Upstream references and immutable revisions
are recorded in the feasibility audit and native-probe notices.

There are no Celeste assets, game assemblies, FMOD SDK files or signing
credentials in this test kit. This checkout's repository license is supplied
separately as `REPOSITORY_LICENSE.txt`.

## MonoMod and Cecil

MonoMod Core **1.3.1**, RuntimeDetour **25.3.1** and Utils **25.0.9** are built
from commit `dfc30a1506d37fb88a2c2be004f525205f46a24c`, with the explicit Apple
hosting changes in `monomod-hosting.patch` and `monomod/AppleJitSystem.cs`.
Their upstream MIT license is included under `licenses/MonoMod-LICENSE.txt`.

The pinned Iced submodule is `c50f29b7bc305696895c075f3fc7719751426b12`, built
as MonoMod.Iced. Its MIT notice is included under `licenses/Iced-LICENSE.txt`.
The closure also includes NuGet Mono.Cecil **0.11.6** (Cecil, Rocks, Pdb, Mdb),
MonoMod.Backports **1.1.2**, and MonoMod.ILHelpers **1.1.0**. Their MIT copyright
and permission notices are included under `licenses/`. The latter two packages
identify MonoMod source commit `a1b82852b2574742776af08818487b90b0bfab93`.
`licenses/provenance.json` records the notice sources and hashes.

Upstream MonoMod build tooling requires newer MSBuild, so an isolated official
.NET SDK **9.0.300** is used only to compile these dependencies. The imported
fixture still targets net8.0 and is built by SDK **8.0.422**. No SDK, macOS Mono
runtime, desktop native helper or signing credential is shipped in the IPA.
The private dependency receipt records all restored NuGet package hashes and
all ten delivered assembly hashes. Both SDK archives are pinned by SHA-512.
