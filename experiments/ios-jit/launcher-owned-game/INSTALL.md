# Private installation

Use the unsigned IPA to update the existing Cabrillo app/LiveContainer slot.
Preserve its data. Follow [PHONE_README.txt](PHONE_README.txt) for the first
original-ZIP import, JIT, cached relaunch and diagnostics. This version prepares
game code on-device; no Celeste code or assets are in the IPA. FMOD permission
is still required before public redistribution.
