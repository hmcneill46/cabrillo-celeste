# Install build 33

Update Cabrillo in the existing Celeste LiveContainer slot 1 and keep its data.
Use the unsigned `Cabrillo-0.17.0-build-33-unsigned.ipa` in this kit.

Follow `README-FIRST.txt` for the focused backup/restore/rollback test.
Backups work before enabling JIT. For gameplay, leave LiveContainer JIT OFF,
leave its saved script blank and enable Fix File Picker. StikDebug stays in slot 2;
use the fresh PID-specific request, detach, and return to Run Celeste.

Accepted build32 remains the fallback. Preserve all Results folders. This private
phone kit is distinct from the public source repository and is not a public IPA.
