# Cabrillo 0.23.0 — Home Screen shortcut setup (build48)

This lane adds an in-app setup sheet and two bundled Apple-signed import templates.
The LiveContainer template asks for an exact app/data launch link generated by
Cabrillo. The standalone template opens Cabrillo directly. Both keep the current
native JIT provider, network recovery and verified/detached readiness gates.

Standalone Cabrillo can use a StikDebug guest in LC2 after the owner provides that
helper’s launch link. Guests retain shared-helper discovery. Same-host LC2
Cabrillo/StikDebug is rejected before changing networking.

All199 managed assemblies and16 runtime archives remain47-identical. The47 launch
reducer is unchanged. See the [48 report](../../../docs/ios-jit/SHORTCUT_SETUP_BUILD_48.md),
[setup guide](../../../docs/HOME_SCREEN_SHORTCUT.md) and
[build instructions](../../../docs/BUILDING.md). Final package hashes and physical
evidence are recorded in the report/ledger. Public IPA distribution remains gated
on FMOD permission; no new publication is authorized.
