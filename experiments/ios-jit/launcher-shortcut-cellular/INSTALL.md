# Build50 installation

Finish any active Celeste game with normal Quit. Replace the existing Cabrillo
guest in LiveContainer with this IPA, keeping its data container. Keep LC JIT off,
its saved script blank, and Fix File Picker on. Keep your existing Cabrillo
shortcut revision49; no shortcut import or Home Screen icon change is needed.

In Automatic mode, start with Wi-Fi off and cellular on, LocalDevVPN disconnected.
Close idle Cabrillo/LiveContainer and StikDebug/LiveContainer2, then run Cabrillo
once from the Home Screen. Expect automatic return, JIT ready and the selected
networking preset restored. Save Export diagnostics in build50/Results.
New installations can use Settings → Home Screen shortcut → Add Home Screen
shortcut, which contains the accepted revision49 template.
